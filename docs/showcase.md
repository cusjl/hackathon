# 风采墙接口与业务规则

本模块独立于数据面板。比赛结束后，由队长选择公开本队项目；首版不设获奖限制和发布前审核。

## 发布流程

1. 调用现有作品及版本接口，选择本队的来源轮次和版本。
2. 将需要公开的内容填入 `PUT /showcase/team/{teamId}`。可补充项目名称、摘要、架构介绍、Git 地址、协议、视频、Demo 和封面。
3. 在管理详情中预览，携带当前 `version` 调用发布接口。
4. 游客通过公开列表和详情浏览。修改已发布内容时先撤回，保存后重新发布。

每支队伍仅有一条展示记录；队伍本身属于单场赛事。来源 `submissionId + versionNo` 必须属于本队。展示正文独立保存，参赛作品后来补交不会自动改变展示内容。保存接口不隐式导入来源内容，前端应先读取所选版本并明确填入。

赛事结束依据 `event.liveEnd`，使用应用业务时间判断。草稿允许内容不完整；发布必须有架构介绍、仓库地址、开源协议及演示视频。视频文件与外部视频 URL 二选一。平台不自动检查外部仓库是否公开或协议文本是否与仓库一致，页面应原样标注作者所选协议，不能将所有项目都宣称为允许自由再利用。

## 状态

| 当前状态 | 操作 | 结果 |
|---|---|---|
| 不存在 | 队长保存 | DRAFT |
| DRAFT / WITHDRAWN | 队长保存 | 保持原状态 |
| DRAFT / WITHDRAWN | 队长发布 | PUBLISHED |
| PUBLISHED | 队长撤回 | WITHDRAWN |
| 非 BLOCKED | 本赛事管理员下架 | BLOCKED |
| BLOCKED | 本赛事管理员解除下架 | WITHDRAWN，不自动公开 |

已发布项目不能直接编辑；下架项目不能由队长编辑、撤回或自行重新发布。所有修改需要当前版本，过期版本返回 HTTP 409 / 4002。操作记录包括保存、发布、撤回、下架与解除下架。

## 接口

| 方法与路径 | 权限 | 用途 |
|---|---|---|
| GET `/showcase/list` | 游客 | eventId、trackId、keyword、page、size 筛选分页 |
| GET `/showcase/{showcaseId}` | 游客 | 公开详情 |
| GET `/showcase/team/{teamId}` | 本队成员、赛事管理员 | 管理详情；尚未创建时 data=null |
| PUT `/showcase/team/{teamId}` | 队长 | 赛后创建或更新草稿 |
| POST `/showcase/team/{teamId}/publish` | 队长 | 发布 |
| POST `/showcase/team/{teamId}/withdraw` | 队长 | 撤回 |
| GET `/showcase/event/{eventId}/manage/list` | 赛事管理员 | 按状态、赛道、关键词查询 |
| PUT `/showcase/event/{eventId}/{showcaseId}/moderation` | 赛事管理员 | 下架或解除下架，原因必填 |

超管继承赛事管理员权限，但不替代队长表达公开意愿。管理接口与公共接口使用不同的返回字段：游客不会获得来源版本、操作日志、成员个人信息或评审信息。

列表按发布时间、项目 ID 倒序排列；关键词按标题或摘要包含匹配，`%`、`_` 按普通字符处理。公开详情对草稿、撤回、下架和赛事未结束统一返回 404 / 3501。

## 保存字段语义

保存为展示内容的全量替换。`title`、`sourceSubmissionId`、`sourceVersionNo` 必填。首次创建不传 `version`，后续修改必须传当前版本。

可选内容缺省或 null 均清空；`imageFileIds` 缺省、null 或 `[]` 均清空图片引用。需要保留封面、视频或图片时，必须继续传其 ID。不要把这一语义与作品提交的标签字段混用：标签缺省/null会保留。

`introMd` 为 Markdown 源文。前端必须使用安全 Markdown 渲染，禁用原始 HTML 和危险链接协议；不要直接插入 innerHTML。项目图片以 `imageFileIds` 上传和关联，展示时使用返回的 `files` 按需获取 URL。不要在 Markdown 中永久保存会到期的签名 URL。外部链接只作为展示地址，服务端不抓取或代理任意网址。

## 文件权限和保留

- 使用现有 `/file/team/{teamId}/showcase` 上传封面、图片或视频，完成上传后仍是私有文件。
- 本队成员、上传者及赛事管理员可按现有角色权限预览。
- 仅被已发布项目实际引用的 SHOWCASE 文件和来源版本的 SUBMIT_VIDEO 文件可匿名读取。其他参赛文件不会随之公开。
- 引用参赛视频时，必须等于所选来源快照中的 videoFileId，不能绑定本队任意历史视频。
- 引用文件必须 READY、属于本队和本赛事，且 MIME 类型符合图片或视频角色。文件锁与外键保护发布/删除竞态。
- 任何展示记录仍引用的文件，包括草稿和撤回状态，都不能删除；需要先修改展示内容解除引用。清理任务排除引用文件。
- 公开文件签名 URL 有效期为 5 分钟。撤回/下架停止新的公开授权，但已有 URL 在到期前仍可能访问。
- 展示记录不设自动过期。赛事、队伍、来源版本等关联通过外键保留，不级联删除成果。外部视频、Git 和 Demo 地址的长期可用性仍由外部服务决定。

## 错误码

- 3501：项目不存在或未公开。
- 3502：赛事尚未结束。
- 3503：当前状态不允许操作。
- 3504：来源作品不属于本队。
- 6011：文件仍被展示引用。
- 参数、鉴权、版本冲突和文件状态复用现有错误码。

数据库迁移：`V10__showcase.sql`。完整可导入接口契约见同目录 `openapi.yaml`。
